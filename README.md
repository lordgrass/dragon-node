# Dragon Node

## A game/modpack for the luanti engine



### About

Dragon node is a Luanti game inspired by the Minecraft

mod Dragon Block C.



### Planned Features

* Dragon Nodes: Naturally spawning nodes that you can find all around your

world, collect seven and place them in an "H" Pattern to summon the eternal

dragon.



### Branches

The base branch holds an unmodified version of
Mineclonia at this time, and will additionally
hold unmodified copies of other code as well if needed.
